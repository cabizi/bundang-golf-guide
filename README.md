# 분당 근교 골프장 추천 AI Skill

분당을 출발점으로 자동차로 약 90분 이내에 있는
골프장을 조사하고 비교하여 추천하는 AI Skill입니다.

## 주요 기능

- 분당에서 골프장까지 이동거리 및 예상시간 조사
- 그린피, 카트비, 캐디피 등 라운딩 비용 비교
- 최근 이용자 리뷰를 활용한 장점과 단점 분석
- 코스 및 시설 만족도 비교
- 골프장 주변 맛집 최소 3곳 추천
- 목적별 최적 골프장 추천

## 활용 예시

"이번 토요일 분당에서 1시간 30분 이내 골프장 중
20만원 정도의 예산으로 갈 만한 곳을 추천해줘.
골프장 장단점과 라운딩 후 갈 만한 맛집도 알려줘."
